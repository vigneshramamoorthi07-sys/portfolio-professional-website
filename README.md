# Vignesh — Personal Developer Portfolio Website

A modern, high-converting, and responsive developer portfolio website designed for **Vignesh**, an aspiring Web Developer and Computer Science graduate (2023).

Inspired by contemporary editorial and poster developer portfolios with dark-theme styling, bold typography, glassmorphism, subtle red/purple ambient glows, and clean component architecture.

---

## 🚀 Features

- **Editorial Reference Design**: High-impact typography, background poster text watermark (`PORTFOLIO`), dark charcoal tones, subtle red/crimson accents, and glassmorphic cards.
- **Sticky Navigation Bar**: Smooth scrolling, active section tracking, hamburger navigation for mobile, and a highlighted **"Download Resume"** CTA.
- **Hero Section**:
  - Live animated typing subtitle (*"I'm a Web Developer"*, *"I Build Responsive Websites"*, *"I'm Passionate About Technology"*).
  - Terminal-style developer visual card with active status.
  - CTAs for **"Explore My Work"** and **"Contact Me"**.
  - Metric counters (*B.Sc CS*, *6 Months Internship*, *2+ Projects*, *Immediate Joiner*).
- **About Me Section**: Full biography, education origin, 4 highlighted strength cards, and an inspiring quote banner.
- **Categorized Technical Skills**:
  - Categorized breakdown (*Web Development, Frameworks, Databases, Tools, Office*).
  - Filterable skill tabs and animated proficiency progress bars.
  - **5-Step Work Process Timeline** (01 Discover → 02 Ideate → 03 Design → 04 Develop → 05 Deliver).
  - Soft skills with iconography and spoken languages tags.
- **Selected Projects**:
  - **Art Gallery Management System** (HTML, CSS, JavaScript, Bootstrap, MySQL).
  - **Online Learning Platform** (HTML, CSS, JavaScript, Bootstrap, MySQL).
  - Project filter tags, key architectural features, GitHub placeholder buttons, and interactive **Project Detail Modal**.
- **Internship Timeline**: Modern timeline showcasing 6-month experience as **Web Developer Trainee** at **Aimore Technologies** with tools and highlights.
- **Education Section**: B.Sc Computer Science (Hindusthan College / Bharathiar University), HSC (Paalam Matric), and SSLC.
- **Functional Contact Form**: Input validation for name, email, subject, message with automated pre-filled client mail triggering.
- **Resume Modal & Print/PDF Export**: Dedicated printable and exportable modal for recruiters to view or save Vignesh's resume as a PDF directly.
- **Deployment Ready**: Configured for instant deployment on Vercel or Netlify.

---

## 🛠️ Tech Stack

- **Framework**: React.js 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React
- **Fonts**: Outfit, Inter, Poppins, Playfair Display

---

## 💻 Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel or Netlify

- **Vercel**: Import this project directory directly in Vercel. Framework preset will automatically be set to **Vite**.
- **Netlify**: Connect repository or run `npm run build` and publish the `dist` directory.
